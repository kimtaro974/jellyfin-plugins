# Dépôt de plugins Jellyfin

Dépôt personnel de plugins pour Jellyfin 12.4.

## Ajouter le dépôt dans Jellyfin

Tableau de bord › Extensions › Dépôts › « + » :

- Nom : `kimtaro974`
- URL : `https://raw.githubusercontent.com/kimtaro974/jellyfin-plugins/main/manifest.json`

Puis Catalogue › « Aperçu au survol » › Installer, et redémarrer Jellyfin.

## Plugins

- **Aperçu au survol** : fenêtre flottante avec extrait vidéo en boucle au survol des vignettes.
